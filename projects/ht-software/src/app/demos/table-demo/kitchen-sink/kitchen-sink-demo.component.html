Kitchen Sink

Every feature exported by ht-quick-angular-table, wired up against a single sample dataset. Backend-dependent features (AI builder, AI summary, agent, skills) respond via a mock service — swap in provideHtBackend() with a real URL + key to go live.

Multi-type columns, selection, actions, add / delete / save

  • String, number, boolean, and date-string columns
  • Object column — computed Supplier display from nested fields
  • Hyperlink column — clickable Docs link
  • Simple filter + sortable headers
  • Pagination with pageSizeOptions: [5, 10, 25]
  • Multi-row selection (shift-click to range-select) + snackbar notification
  • Row action menu with edit + delete icons
  • Toolbar buttons: Add row, Delete selected, Save
